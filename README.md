# NexaBrokers - Crypto Broker Platform

A premium, production-ready crypto broker platform built with Python and Flask. Features user authentication, financial dashboards, a full admin review panel, CSRF protection, and rate limiting.

## Tech Stack
- **Backend:** Python, Flask, Flask-SQLAlchemy, Werkzeug
- **Security:** Flask-WTF (CSRF), Flask-Limiter, PostgreSQL / SQLite compatibility
- **Server:** Gunicorn
